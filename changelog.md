## 2026-11-21 — Build Unblock & Schema Correctness Pass
- **Bug (build blocker):** `app/build.gradle.kts:11` — `java.util.Properties()` did not resolve. In a Kotlin DSL script the bare identifier `java` resolves to Gradle's `java` extension and shadows the `java` package. Kotlin and KSP never ran, so the previously reported KSP `MissingType` error was never reached by run #26.
- **Fix:** Added `import java.util.Properties` at the top of `app/build.gradle.kts`.
- **Bug (CI, introduced by the previous pass):** Secrets were written into `local.properties` with `cat >`, which destroys the `sdk.dir` entry the Android SDK needs.
- **Fix:** Secrets are now passed as Gradle project properties (`-PSANDE_GOOGLE_CLIENT_ID=…`, `-PSANDE_GOOGLE_ANDROID_CLIENT_ID=…`, `-PSANDE_API_BASE_URL=…`). `configValue()` also hardened to `as? String` + `takeIf { it.isNotBlank() }`.
- **Bug (compile):** `LegacyAdoptionManager.kt` referenced a schema that no longer exists — the deleted `StockAdjustment` entity, a non-existent `businessDao()` / `stockAdjustmentDao()`, five non-existent DAO methods, `Outbox.copy(businessId=…)` on an entity without that field, `Business.copy(deletedAt=…)` on an entity without that field, and `.await()` on a `Unit`-returning function.
- **Fix:** Rewritten against the current schema. Added `countByBusiness` / `getAllByBusiness` to `ProductDao`, `MovementDao`, `MemberDao`, `OutboxEntryDao`; `update` to `MemberDao` and `SaleHeaderDao`; and a new `BusinessDao`.
- **Bug (compile):** `SyncWorker.kt` imported `com.example.sande.data.api.ApiClient` — the package is `data.remote`.
- **Bug (compile):** `SessionManager.kt` used `GoogleAuthRequest` without an import. `AppDatabase.kt` used `DeviceRegistrationDao` without an import.
- **Bug (compile):** `ReportsTest.kt` imported `ReportsViewModel` from `data.repository` — it lives in `ui.viewmodel`.
- **Bug (Room, compile + runtime):** `MembershipMirror` declared `Index("syncedAt")` on a field named `lastSyncedAt`, and `MIGRATION_4_5` created the index on the same non-existent column.
- **Fix:** Both changed to `lastSyncedAt`.
- **Bug (Room, runtime):** `MIGRATION_4_5` created `stock_movements`, `sale_items` and `product_price_history` without the foreign keys their entities declare — Room's schema validation rejects the migrated database.
- **Fix:** Added the matching `FOREIGN KEY … ON DELETE …` clauses.
- **Bug (Room, runtime):** `MIGRATION_4_5` copied `outbox` → `outbox_entries` selecting `businessId`, `payloadJson`, `attemptCount`, `lastError`; the legacy `outbox` table has `payload`, `attempts` and no `businessId`, so the migration aborted with "no such column".
- **Fix:** Mapped old → new explicitly (`payload`→`payloadJson`, `attempts`→`attemptCount`, `businessId` derived from the `businesses` table).
- **Bug (Room, runtime):** `MIGRATION_4_5` inserted `sale_items.unitPriceCents` / `totalCents` from a nullable source and `categoryName` from a `LEFT JOIN`, violating their `NOT NULL` constraints.
- **Fix:** `COALESCE` on all three, and a `JOIN products` on the `movements` copy so the new foreign key always holds.
- **Security:** Ktor logged at `LogLevel.ALL`, writing OAuth tokens and business records to logcat. Now `LogLevel.INFO` in debug, `NONE` in release, with `sanitizeHeader` on `Authorization`.
- **Repo hygiene:** Untracked `backend/node_modules` (5 120 files), `control-centre/node_modules` (139) and `control-centre/dist` (8); added `node_modules/`, `dist/`, `.wrangler/` to `.gitignore`.
- **CI:** `backend/.github/workflows/backend-ci.yml` never ran — GitHub Actions only reads workflows from the repository root `.github/workflows/`. Moved to `.github/workflows/backend.yml`; deployment moved to a manual `.github/workflows/backend-deploy.yml` because the `staging` and `production` environments still have `PLACEHOLDER_*_ID` resource IDs.
- **CI:** `ci.yml` now uses `gradle/actions/setup-gradle` for caching, runs `testDebugUnitTest` and `lintDebug`, and type-checks + builds the Control Centre.
- **Tests:** `DatabaseMigrationTest` and `FullMigrationTest` moved from `src/test` to `src/androidTest` — they use `InstrumentationRegistry` and `MigrationTestHelper`, which cannot run as JVM unit tests. `room-testing` and `androidx.test.core` moved to `androidTestImplementation`.
- **Verified:** git history shows schema versions 1, 4 and 5 **never existed**; the real chain is v3 → v6. Every table present at v3 has identical columns in v6, and `MIGRATION_4_5` creates all 13 new tables.
- **Added:** `tools/check_imports.py`, `tools/check_dao_calls.py`, `tools/compare_entities.py` — static checks that stand in for the missing local compiler. All report clean.
- **Outstanding:** Room schema JSON (`app/schemas/6.json`) is generated by the CI build and must be committed before the instrumented migration tests can run; `wrangler.toml` staging/production IDs are still placeholders; backend route handlers have no tests.
